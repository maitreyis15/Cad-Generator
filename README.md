This code was generated by Claude code with some additional comments from me (Maitreyi Sarkar). This code was read through by me as well.

I created the examples of different pushbutton variations myself to serve as reference (around 30-40 examples). I also provided the Rockwell Automation pushbutton file within this repository. 


This README.md is also not written by AI so that important assumptions and locations can be properly noted. 


Summary: Ranges are set so that the pushbutton geometries can be altered using a python add in called CadQuery. CadQuery allows you to code different CAD geometries, this makes the pushbutton generation a lot more simplified. This gets rid of the need to have Claude operate even through a wrapper, so the entire CAD generation process is automated. The goal for me would to have it switch between mechanisms.

The outputs are usd files that be used as Isaac Sim training files.


ASSUMPTIONS:
-This code is only written for pushbutton type of mechanisms right now and because it is written by Claude, the current scalability is limited. 

-New outlines need to be included within  footprint, sample_footprint and then families

-The step file must be aligned with z-axis for it to properly detect the mounting point
    - It finds the mounting point so far by finding the highest flat plane with the normal pointing along the z-axis.
-Weights are set in the config.yaml file, this should be edited because the numbers are just random starting points. It is so that you get a specific number of different type of push button styles
-A convex hull is included with dish and dimple types because the robot would never feel it, I definetely want to think through this coding choice and will probably end up changing this

Important Notes:
-The main program that is called when you run through terminal is through cli.py
Config.yaml
    -If the reference file name changes you need to update this in the config.yaml
    -If the models keep throwing errors, that is because the range set in config.yaml is not accurate!! 

    (If you didn't notice the config file will be the one that might have to be altered the most)

body.py
    -This will check for interference when this runs
    -This detects mounting position
    -The width reference is set from this file

shapes.py
    -This is the part where CadQuery heavily influences the code
    -Generates 2d sketches and extrudes to a set height h
    -The different fillets and dome shapes/divots are set by pushbutton type and button top type
    -The z-axis is the press axis

usd_export.py
    -Converts the STEP files to USD
    -Converts dimensions to meters because that is how Isaac Sim works
    -Generated with the pxr module to be faster
    -Training code can reate pb:press_Threshold_m to figure out buttom press counts
    -collision enabled is false
    -Colliders for convex hell and convex decomposition are included



-preview.py is optional.



    family    : "rect" | "round" | "tri"
    footprint : rect  -> width, length, corner_r, yaw_deg
                round -> diameter
                tri   -> side, corner_r, yaw_deg
    top       : style + base (straight-side height) + style-specific values
                dome    -> h
                flattop -> h, h_cut
                dimple  -> h, dimple_d, dimple_depth
                dish    -> depth, rim
                pillow  -> edge_r
    neck      : optional {"diameter", "height"} -> mushroom head on a stem
